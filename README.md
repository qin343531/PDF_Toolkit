# PDF_Toolkit

## ✦ PDF 工具箱 — 功能简介

   ---

   ### 📄 页面处理

   | 功能 | 说明 |
   |------|------|
   | 🗑️ 删除空白页 | 自动扫描全文档，按字符数阈值判定空白页，支持一键批量删除 |
   | 📑 删除指定页 | 支持单页（7）、范围（3-5）、混合（1,3,7-9）多种输入格式 |
   | 📋 提取页面 | 将指定页码范围提取为独立的新 PDF 文件 |
   | 🔄 手动旋转 | 对指定页旋转 90°/180°/270° |
   | 🤖 智能旋转 | 自动检测每页宽高比，批量将竖版→横版 或 横版→竖版 |
   | 🔢 页面排序 | 自定义顺序重排（如 3,1,5,2,4），或一键反转全部页面 |

   ### 🔗 合并与拆分

   | 功能 | 说明 |
   |------|------|
   | 🔗 合并 PDF | 多文件按顺序合并为一个，支持拖入排序、上移下移 |
   | ✂️ 拆分 PDF | 三种模式：每页独立拆分 / 每 N 页一组 / 按自定义页码范围拆分 |

   ### 🔧 更多工具

   | 功能 | 说明 |
   |------|------|
   | 💧 文本水印 | 自定义文字、透明度，斜铺叠加到每一页 |
   | 📦 压缩 PDF | 压缩页面内容流，减小文件体积，显示压缩率 |
   | 📝 提取文本 | 将全部页面文字提取为 TXT 文件 |
   | ℹ️ 文档信息 | 查看元数据（标题/作者/创建时间）+ 页面尺寸分布统计 |
   | 🔒 移除密码 | 输入密码解密受保护的 PDF |

   ---

   ### 技术特点

   - 免安装：单文件 exe，内含完整运行环境，复制到任意 Windows 电脑即用
   - 可视化：tkinter 原生 GUI，三标签页布局，无命令行操作
   - 批量处理：删除/旋转/提取均支持一次性批量操作
   - 本地处理：所有操作在本地完成，不上传任何文件到网络
   - 自动输出：默认保存到同级 output 目录，可自定义路径

   ### 技术栈

   Python · tkinter · pypdf · reportlab · PyInstaller
